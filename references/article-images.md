# 可选主题配图

## 开关和流程

默认关闭；仅明确要求配图时执行。事实核查和配图开关互不触发，人设与网站格式检查仍必做。原样上传不自动加图；草稿只交付预览，不发布。用户只要求配图、不改正文时，保留正文，仅做授权的图片接入。已有合适配图保留，不自动替换；明确替换时另存新版本。

在最小人设适配和已开启的核查结束后，通读全文，用一句话概括核心主题，选择一个具体场景。法律、职业、生活观察、健康等分别按主题选图，不固定使用律师、法槌或天平。不得为迁就画面改写文章。

## 生成与真实性边界

使用当前可用的内置 image_gen 工具；有 imagegen Skill 时遵循它，不自建 API、不给用户索要密钥。工具不可用或失败时报告，不能用占位图冒充生成结果，也不能静默切换收费 API。是否无图发布由用户决定。

一次生成一张写实主题示意图：横向 16:9，干净构图、自然光线、克制色彩、真实质感、不叠加标题文字或水印。不强行给照片染黄紫色。画面不能冒充某真实事件、公司项目现场或用户本人；避免可识别客户、企业内部资料、品牌标志和虚构统计。健康主题不暗示诊断、疗效或未经核实的医学机制。

提示词记录：文章主题、具体场景、写实风格、16:9 构图，以及不冒充真实现场／本人、不加文字标志等限制。生成后检查主题、肢体／物体结构、可读文字、误导性细节；必要时做针对性重生成，不无限重试。生成图不属于事实核查证据。

## 优化为发布图

保留生成原图与提示词于本机审核目录，不将原图加入网站或 Git。只优化选定图：EXIF 方向校正、必要的经确认裁剪、缩放和 WebP 编码，不使用脚本重绘或改变画面内容。可用 Pillow；缺失时说明依赖，不偷偷安装。

在 Skill 目录运行（输出路径为实际网站目录，不能覆盖已有文件）：

```powershell
python -X utf8 scripts/optimize_article_image.py "选定原图.png" "F:\Git上的程序等等\sumin_website\public\article-assets\文章ID\cover.webp"
```

已检视并允许中心裁剪时可追加 `--crop`；否则非 16:9 输入会被拒绝。裁剪后必须再次检查主体，不能只依赖脚本成功。默认不放大小图，宽度最多 1200px。目标 150–300KB；清晰的小文件不必增大。脚本在质量 85→60 范围试编码，无法达到 300KB 时保留结果并返回状态 2，提示人工审阅，不继续无限降低质量。透明通道保留。输出含尺寸、体积、质量和预算状态。

检查 WebP 可解码、比例和主体无误，再用网站已有封面指令插入标题下、正文前：

```markdown
:::figure{type="cover"}
![描述实际画面的替代文字](/article-assets/<文章ID>/cover.webp)

*图片由AI生成*
:::
```

AI 封面图注固定写作“图片由AI生成”，无句号，用 Markdown 星号包裹显示为斜体；不要改普通图表说明。此简短来源标记不改变上面的真实性边界。

纯文字文章不插入空白占位。真实照片／原稿图片保留其归属，不自动标为 AI 图。生成配图不将正文来源分类改为 AI 共研，来源分类仍由用户确认。

## 发布验证

运行文章校验和网站构建，验证图片 URL、加载、图注、替代文字、桌面与手机无横向溢出，并检查图片加载前后正文位移。检查普通图片仍按原方式显示，无图文章布局未变。交付说明核查／配图开关、主题、最终提示词、原图和发布图路径、尺寸、体积与未完成项；Git 提交只包含授权的正文、图片和必要索引，不包含原图、提示词、测试素材。
